# 패션 브랜드 아카이브 — 데이터 수집

위키데이터에서 국내·해외 패션 브랜드 정보를 모아 `data/` 폴더에 저장합니다.

## 실행 방법
1. 저장소의 **Actions** 탭 → **브랜드 데이터 수집** → **Run workflow**
2. 10~30분 뒤 `data/brands.xlsx` 가 생성됨 (이후 매주 월요일 새벽 자동 갱신)

## 수집 항목
브랜드명(한/영), 상태(활동중/사라짐), 설립연도, 사라진 해, 국가, 모회사, 창립자, 설명,
공식 사이트, 인스타그램, 위키백과 링크, 네이버쇼핑 검색 링크, 자유 라이선스 이미지, 인지도 지수

- **인지도 지수**: 그 브랜드 문서가 있는 위키백과 언어판 수. 순위 정렬의 기본값.
- **카테고리**: `seed/global_brands.csv`(해외)·`seed/korean_brands.csv`(국내)에 지정한 값이 우선, 없으면 위키데이터 유형·설명으로 추정. 카테고리를 `제외`로 적으면 목록에서 빠지고 `그룹`으로 적으면 기업·그룹으로 분류.
- **수집 경로**: 위키데이터에서 '패션 브랜드'로 분류됐는지, 업종이 '패션 산업'인지 등. 노이즈 걸러낼 때 사용.

## 결과 파일
| 파일 | 용도 |
|---|---|
| `data/brands.xlsx` | 검토용 (요약·전체·활동중·사라진 브랜드·국내 브랜드 시트) |
| `data/brands.csv` | 구글시트 등으로 가져가기 |
| `data/brands.json` | 사이트에서 바로 사용 |
| `data/stats.json` | 수집 통계 |
